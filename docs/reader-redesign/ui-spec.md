# UI 规范 v1（阶段 B 交付物）

对应你的反馈：「UI 难看」。这里给出可执行的视觉与布局规则，供实现与验收对照。

配套原型：`prototype/workspace-prototype.html`（单文件，浏览器直接打开）
截图：`prototype/workspace-both.png`

> 原型只表达**信息层级与交互位置**，灰度与间距可直接复用；不追求像素级复刻。

---

## 1. 设计令牌（唯一来源，禁止散落硬编码）

### 颜色

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#f5f6f8` | 应用背景 |
| `--panel` | `#ffffff` | 工具栏、面板 |
| `--line` | `#e3e7ee` | 分隔线、卡片描边 |
| `--text` | `#1d2129` | 正文与标题 |
| `--muted` | `#5b6472` | 次要信息、辅助说明 |
| `--faint` | `#98a2b3` | 极弱信息（页码、来源） |
| `--accent` | `#2f6bd8` | 主操作、选中、链接 |
| `--accent-soft` | `#e9f0fd` | 选中底色、徽标底色 |
| `--reader-bg` | `#2a2d33` | 阅读区衬底（深色，突出纸张） |
| `--mark-yellow` | `rgba(255,206,0,.45)` | 高亮标注 |

对比度要求：正文与背景 ≥ 7:1；`--muted` 与 `--panel` ≥ 4.5:1。
**不要**使用大面积渐变装饰、半透明彩色描边。

### 字号

| 用途 | 字号 | 字重 |
|---|---|---|
| 应用名 / 主题名 | 13–14 px | 600 |
| 卡片标题 | 12.5 px | 600 |
| 卡片正文 / 评论 | 12 px | 400 |
| 摘录原文 | 11.5 px | 400（`--muted`） |
| 徽标 / 页码 / 提示 | 10.5–11 px | 500 |

正文永不小于 11 px；仅在 200% 系统缩放时允许 10.5 px 徽标。

### 间距与形状

`4 / 8 / 12 / 16 / 24` 五档；卡片内边距 8–9 px；卡片间距 13 px；列间距 30 px。
圆角：面板 0，卡片 10 px，按钮 6 px，徽标 4 px。
阴影只有一档：`0 1px 2px rgba(16,24,40,.05), 0 2px 6px rgba(16,24,40,.07)`。

## 2. 布局

```
┌ 顶栏 44px ─────────────────────────────────────────────┐
│ 品牌 │ 文档标签页 │              │ 模式切换 ▸ ▸ ▸      │
├ 工具条 32px ───────────────────────────────────────────┤
│ 主题名·摘录数        [＋节点 折叠 适配 导出]            │
├──────────────┬─┬───────────────────────────────────────┤
│  脑图区      │▮│  阅读区                               │
│  (可折叠)    │ │                                       │
│              │ │                                       │
├──────────────┴─┴───────────────────────────────────────┤
│ 状态条 28px：操作提示 / 定位状态                        │
└────────────────────────────────────────────────────────┘
```

### 三种模式

| 模式 | 脑图区 | 阅读区 | 用途 |
|---|---|---|---|
| 专注阅读 | 隐藏 | 100% | 连续阅读 |
| 阅读整理 | 47%（可拖 300px–窗口宽-340px） | 剩余 | 边读边记（默认） |
| 专注脑图 | 100% | 隐藏 | 集中整理 |

规则：

- 分隔条宽 5 px，悬停加深；拖动实时生效，松手后记住宽度。
- 模式与分栏宽度写入设置，下次启动恢复。
- 全部区域的工具条高度统一 32 px，文字基线一致（当前版本各行高度不一，是最明显的"乱"）。

## 3. 工具分组（解决"工具栏拥挤"）

| 位置 | 内容 |
|---|---|
| 顶栏左 | 品牌、文档标签页、`＋ 添加资料` |
| 顶栏右 | 模式切换（三段式） |
| 脑图工具条 | `＋ 节点`、`折叠`、`适配全图`、`导出` |
| 阅读工具条 | 选择/高亮/下划线/手写（互斥组）、页码、适宽/100%、目录 |
| 更多菜单 | 导出、同步、备份、设置、AI、朗读 |

原则：

1. 一屏只保留**当前任务必需**的操作。
2. 互斥工具用同一组按钮 + 单一激活态，不用多个独立开关。
3. 图标 + 文字优先于纯图标；纯图标必须有 `tooltip`。
4. 低频操作一律进「更多」，不得平铺。

## 4. 卡片（脑图节点）规范

```
┌─────────────────────────────┐
│ 标题            [原文 p.1]  │  ← 标题 12.5/600；徽标 10.5
│ ┌─────────────────────────┐ │
│ │ 摘录原文（最多 3 行）    │ │  ← 左侧 2px 竖线，底 #fafbfd
│ └─────────────────────────┘ │
│ 自己的评论                   │  ← 12/400 --text
│ ─────────────────────────── │
│ 来源可回溯        [定位原文] │  ← 10.5 --faint + 右对齐按钮
└─────────────────────────────┘
```

- 主题节点与摘录节点**视觉必须可区分**：主题用 `--accent-soft` 底色，摘录用白底 + 来源徽标。
- 摘录用 `-webkit-line-clamp: 3` 等价能力截断，不允许撑高卡片。
- 选中态：描边 `--accent` + 3 px 外发光。
- 悬停态：描边加深，不改变尺寸（避免布局抖动）。

---

## 5. 高 DPI 与尺寸

- 所有图标使用 SVG 或提供 `@2x`；不使用位图放大。
- 125% / 150% / 200% 下：文字不截断、按钮不换行、工具条高度按逻辑像素保持。
- 页面渲染已按设备像素比出图（见 `rendering-spec.md`），UI 侧不要再用图片放大替代。

---

## 6. Qt 落地映射

| 规范 | 实现 |
|---|---|
| 模式与分栏 | `QSplitter` + 记住 `saveState()` |
| 顶栏标签 | `QTabBar`（可关闭、可拖动重排） |
| 工具条 | `QToolBar` + `QActionGroup` 做互斥工具 |
| 令牌 | 单例 `Theme` 类产出 QSS 变量 + `QColor` 常量，禁止散落字面量 |
| 卡片 | `QGraphicsObject`，`paint()` 内按上表绘制 |
| 图标 | `QIcon` + 内嵌 SVG（`:/icons/*.svg`） |
